
## Run Locally

**Prerequisites:**  Node.js

Create a `.env.local` file with:
`VITE_TWITTERAPI_IO_KEY=your_twitterapi_io_key`
`VITE_PRIVATE_TWIN_LLM_API_KEY=your_openai_compatible_key`
`VITE_PRIVATE_TWIN_LLM_BASE_URL=your_openai_compatible_base_url`
`VITE_PRIVATE_TWIN_LLM_MODEL=your_model_name`

1. Install dependencies:
   `npm install`
3. Run the app:
   `npm run dev`
